# Host code execution via UnsafeLocalCodeExecutor when API is network-exposed

## Summary
`UnsafeLocalCodeExecutor` spawns subprocesses to execute model-generated code without sandboxing. Combined with unauthenticated `/run`, this enables remote code execution when agents use this executor or skill script tools.

## Evidence
`adk-js@4169319:core/src/code_executors/unsafe_local_code_executor.ts:106-151,202-206`, `adk-js@4169319:core/src/tools/skill/run_skill_inline_script_tool.ts:97-104`

## Attack Chain
Unauthenticated POST `/run` → agent invokes inline script tool → `spawn(command, args)` on host.

## CWE and CVSS
CWE-78; CVSS 4.0 High (requires agent config with unsafe executor).

## Remediation
Never use UnsafeLocalCodeExecutor on network-exposed servers; enforce sandboxed executors in deploy templates.
