# A2A REST/JSON-RPC handlers explicitly disable authentication

## Summary
`toA2a` registers handlers with `UserBuilder.noAuthentication`, allowing unauthenticated remote agent invocation.

## Evidence
- `adk-js@4169319:core/src/a2a/agent_to_a2a.ts:81,110,114`
- `adk-js@4169319:dev/src/server/adk_api_server.ts:144`

## CWE and CVSS
- CWE-306 — CVSS 9.2 High

## Remediation
Enable configurable authentication for A2A endpoints; document secure deployment requirements.
