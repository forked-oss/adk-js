# AdkApiServer exposes agent execution APIs without authentication

## Summary
Development API server accepts unauthenticated requests for `/run`, sessions, artifacts, and debug traces. Cloud Run deploy defaults bind `0.0.0.0`.

## Evidence
- `adk-js@4169319:dev/src/server/adk_api_server.ts:707,738,838`
- `adk-js@4169319:dev/src/cli/deploy/deploy_utils.ts:63`

## CWE and CVSS
- CWE-306 — CVSS 9.2 High

## Remediation
Require authentication for network-exposed deployments; default to localhost-only bind.
