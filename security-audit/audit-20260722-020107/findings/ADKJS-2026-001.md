# Incomplete remediation of express.urlencoded prototype-pollution vector in standalone A2A apps

## Summary
PR #378 removed `express.urlencoded({extended:true})` from AdkApiServer but `toA2a()` still registers it when creating standalone Express apps.

## Evidence
- `adk-js@4169319:core/src/a2a/agent_to_a2a.ts:100-102,110`

## CWE and CVSS
- CWE-1321 — CVSS 6.5 Medium

## Remediation
Remove urlencoded middleware from standalone A2A path or set `extended:false`.
